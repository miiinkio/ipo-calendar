# 공모주 일정 캘린더

코스피·코스닥 공모주(스팩 포함)의 청약일, 환불일, 상장일, 확정 공모가, 주관사, 청약 수수료를 달력으로 보여주는 정적 사이트입니다.

- `index.html` — 사이트 (빌드 결과물, `python3 build.py`로 생성)
- `page.html` — 캘린더 화면 원본
- `data/ipo.json` — 공모주 일정 (매일 아침 자동 갱신)
- `data/fees.json` — 증권사별 온라인 청약 수수료
- `data/meta.json` — 마지막 업데이트 시각

정보 제공용이며 투자 권유가 아닙니다. 청약 전 증권사 공고와 투자설명서를 확인하세요.
